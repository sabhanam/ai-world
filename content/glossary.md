# Glossary

One term per line, as `- **Term**: one-sentence plain definition.` The build adds a hover definition to the first use of each term on every page.
Agents: add a term when a page uses jargon a non-technical reader wouldn't know. Keep definitions under 25 words.

- **API**: a way for one program to ask another program for data or to do something.
- **LLM**: large language model, the kind of AI behind chat assistants, trained on huge amounts of text to predict and write language.
- **open-weight**: a model whose trained parameters are published, so anyone can download and run it themselves.
- **IDE**: integrated development environment, the app programmers write code in, like VS Code.
- **prompt injection**: hidden instructions in a web page or file that try to trick an AI into doing something its user didn't ask for.
- **embedding**: a list of numbers that captures what a piece of text means, so similar meanings get similar numbers.
- **vector database**: a database built to quickly find the embeddings closest to a given one, which means finding text with similar meaning.
- **context window**: how much text a model can read at once, its short-term memory for one conversation.
- **terminal**: the text-only window where developers type commands to their computer.
- **Apache 2.0**: a permissive open-source licence that lets anyone use, change and sell the software, including commercially.
